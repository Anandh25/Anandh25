## 🚀 Featured Projects

### 1. Enterprise Incident & Service Management Portal

A full-stack incident management application with role-based access for Admin, Support Agent and Employee.

**Tech Stack:** React, TypeScript, Node.js, Express.js, MongoDB, Mongoose, JWT

- Role-based authentication and authorization.
- Incident creation, assignment, search and filtering.
- SLA tracking and overdue incident monitoring.
- Comments, edit history and activity audit logs.
- Role-specific dashboards and statistics.

🔗 [Live Demo](https://incidentportal.vercel.app/) | [Source Code](https://github.com/Anandh25/enterprise-incident-portal)

### 2. Job Tracker App

A full-stack job application tracking application built using the MERN stack and TypeScript.

**Tech Stack:** React, TypeScript, Node.js, Express.js, MongoDB, JWT

- JWT authentication and protected routes.
- Job application CRUD operations.
- Search and filtering.
- Server-side pagination.
- Migrated the application from JavaScript to TypeScript.

🔗 [Live Demo](https://job-tracker-2-0-typescript.vercel.app/) | [Source Code](https://github.com/Anandh25/Job-Tracker-App)

### 3. PreethiZign – Handmade Ecommerce Platform

A responsive handmade products ecommerce website developed for a real-world small business.

**Tech Stack:** React, Tailwind CSS, Firebase Authentication, Firestore, Cloudinary

- Firebase authentication.
- CRUD-based admin dashboard.
- Product management using Firestore.
- Cloudinary image uploads.
- Dynamic product rendering and responsive product detail pages.

🔗 [Live Demo](https://preethizign.netlify.app/) | [Source Code](https://github.com/Anandh25/preethizign)
